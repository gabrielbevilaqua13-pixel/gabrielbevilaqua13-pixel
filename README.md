## Featured Projects

### [Speaker AI](https://github.com/gabrielbevilaqua13-pixel/Speaker-AI)
An AI-powered English learning experience designed to help students practice conversation, receive feedback, and keep learning beyond the classroom.

**Stack:** Python · Streamlit · Groq API · Supabase · Google OAuth

### [Reel Word Glow](https://github.com/gabrielbevilaqua13-pixel/Legenda-Reel)
A web application for creating synchronized subtitles for short videos, featuring word-by-word highlighting and video export.

**Stack:** React · TypeScript · TanStack Start · Groq · Render

[Live application](https://reel-word-glow-app.onrender.com)

### [Mestre Interior](https://github.com/gabrielbevilaqua13-pixel/I-Chess)
A chess training platform that analyzes games, identifies recurring mistakes, and turns them into opportunities for improvement.

**Stack:** React · TypeScript · Stockfish · Lichess API · Chess.com API

[Live application](https://mestre-interior.onrender.com)

### [Ibiapaba Guitar Serenades](https://github.com/gabrielbevilaqua13-pixel/ibiapaba-guitar-serenades)
A project dedicated to presenting classical guitar performances and musical services in the Serra da Ibiapaba region of Brazil.
